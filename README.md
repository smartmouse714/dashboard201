# YADa - Yet Another DAshboard

## Description

YADa is a toy project to demo front-end development through productive
struggles.

### Use Case

Support a SaaS product with international colleagues and clients.

## Learning & Development

### CSS

Learn responsive designs

### HTML

Learn semantic elements

### JavaScript

Learn the art of refactoring

### CI/CD

- Automated simultaneous deployment to GitHub Pages and Azure Static Web Apps
  via GitHub Actions.
- [Cloudfare Pages](https://mtidashboard.pages.dev/)
